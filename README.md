# Sean M. Daugherity — Architecture Portfolio

Static website version of the portfolio PDF.

- `index.html` — the portfolio, page by page, with a clickable table of contents and contact/social links
- `resume.html` — the resume on its own page (with a PDF download)
- `assets/pages/`, `assets/resume/` — page images rendered from the PDFs
- `assets/*.pdf` — original PDFs for download

To publish: in the repo's **Settings → Pages**, set the source to the `main` branch, root folder.
